# Симулятор зеркальной камеры RCJ Soccer

Установка (Python 3.12, один раз):

```
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Запуск: двойной клик по `run.bat` (или `.venv\Scripts\python.exe run_sim.py`).

## Порядок работы
1. **Лига** (слева вверху): Open 180 мм или Lightweight 220 мм. Под панелью параметров горят проверки габаритов.
2. **Три высоты.** Камера над полем, объектив → 1-я плоскость зеркала, плоскость зеркала над полем.
   Они связаны (плоскость = камера + расстояние), правьте любые две.
3. **Камера.** Разрешение и HFOV (по умолчанию 70° — замените на реальный для вашего объектива).
4. **Зеркало** — три способа:
   - готовый профиль из списка (радиус и глубина меняются);
   - «Рассчитать и загрузить» в нижнем редакторе: профиль под заданные ближнюю/дальнюю точки пола;
   - «Загрузить STEP зеркала…» (масштаб, переворот, ручная плоскость, если авто-определение ошиблось).
5. **Редактор профиля** (внизу): красные точки тянутся мышью, значения можно править в таблице,
   «+/− точка» добавляет и убирает точки. Жёлтые и оранжевые линии — лучи в сечении, подписи — расстояние до пола.
6. **Расстановка**: панель справа. ЛКМ — мяч, ПКМ — робот; её можно оторвать на второй монитор.
7. **Вкладки результата**: Камера, Вид сверху, Панорама, Калибровка, Мяч в пикселях, Карта видимости, 3D сцена.
